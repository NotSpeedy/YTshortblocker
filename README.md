# 🚫 YouTube Shorts Blocker

**Take back your YouTube. No Shorts, no distractions.**

## ✨ What it does

YouTube Shorts Blocker is a lightweight browser extension that surgically removes Shorts from your YouTube experience — no clutter, no redirects trapping you, no nonsense.

| Feature | Description |
|---|---|
| 🙈 **Hides all Shorts UI** | Shelves, carousels, sidebar links — gone |
| 🔀 **Redirects `/shorts/`** | Automatically sends Shorts URLs to `/watch/` |
| 🔒 **Zero data collected** | No tracking, no analytics, no phoning home |

---

## 🚀 Installation

### Chrome & Edge

```
1. Download & unzip the extension file
2. Open  chrome://extensions  (or  edge://extensions )
3. Enable  Developer mode  in the top-right corner
4. Click  "Load unpacked"
5. Select the unzipped folder
```

### Firefox

```
1. Download & unzip the extension file
2. Open  about:debugging#/runtime/this-firefox
3. Click  "Load Temporary Add-on"
4. Select  manifest.json  from the unzipped folder
```

> **Note for Firefox users:** Temporary add-ons are removed when the browser closes. For a permanent install, the extension would need to be signed via Mozilla's review process.
